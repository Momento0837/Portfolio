협업 프로젝트

팀 안에서 역할을 나누고, 기획과 디자인 방향을 조율하며 결과물을 완성한 프로젝트 기록입니다.

Project Archive

중간고사 발표 자료 기반 협업 프로젝트

폴더에 포함된 발표 PDF를 바탕으로 프로젝트의 흐름, 역할, 산출물을 한 페이지에서 확인할 수 있도록 정리했습니다. 협업 과정에서 필요한 자료 정리, 화면 구성, 발표 자료화까지 이어지는 작업을 중심으로 보여줍니다.

01

기획 정리

프로젝트의 주제와 목적을 팀원과 공유하고, 필요한 기능과 표현 방향을 정리했습니다.

02

역할 분담

각자 맡은 작업 범위를 나누고, 진행 상황을 맞춰 보며 하나의 결과물로 연결했습니다.

03

디자인 구성

자료의 흐름이 잘 보이도록 화면 밀도, 시각 요소, 발표용 페이지 구성을 다듬었습니다.

04

발표 자료화

작업 과정을 설명 가능한 형태로 정리하고, 결과물을 PDF 발표 자료로 완성했습니다.

Role

협업 안에서의 작업 방식

  • 공통 목표 확인 팀원과 같은 방향을 보고 작업할 수 있도록 주제, 일정, 산출물 기준을 먼저 맞췄습니다.
  • 화면과 자료의 연결 단순히 보기 좋은 페이지보다, 발표 흐름 안에서 자연스럽게 이해되는 구성을 우선했습니다.
  • 피드백 반영 팀 작업 중 나온 의견을 반영해 문장, 배치, 시각적 강조점을 계속 조정했습니다.
